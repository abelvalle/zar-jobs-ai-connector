# Soporte

Para dudas, errores reproducibles o solicitudes de funcionalidad, abre una [incidencia pública](https://github.com/abelvalle/zar-jobs-ai-connector/issues) sin incluir URLs RSS privadas, credenciales, cookies, currículos ni datos personales.

Para vulnerabilidades, sigue el proceso privado de [SECURITY.md](SECURITY.md). No publiques detalles explotables en una incidencia.

El proyecto no puede resolver bloqueos de cuenta ni representar a InfoJobs, Tecnoempleo, LinkedIn o Indeed. Esos casos deben tramitarse con el soporte oficial del portal correspondiente.
