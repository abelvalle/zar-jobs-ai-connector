# Zar Jobs AI Connector V1.8

V1.8 incorpora el Hito 30: Skills Radar sobre muestras verificables.

## Entregado

- `analyze_job_skill_radar` para comparar 2–20 ofertas con el CV confirmado.
- frecuencias, proporciones, ofertas de origen y evidencia por rutas;
- vocabulario local ampliable mediante términos explícitos;
- prompt MCP `analyze-skills-radar`;
- límites explícitos contra inferencia de mercado, causalidad y predicción.

## Seguridad

Las ofertas son datos no confiables. Una competencia ausente es una pregunta, no una carencia demostrada, y nunca se añade al CV automáticamente.

## Evidencia de publicación

- 137 pruebas unitarias;
- 54 herramientas MCP locales;
- 7 prompts MCP nativos y 3 recursos;
- smoke local y paquete portable;
- validación de skill, manifests y marketplace.
