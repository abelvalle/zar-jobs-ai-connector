# Zar Jobs AI Connector V1.7

V1.7 incorpora el Hito 29: coach de evidencia y logros.

## Entregado

- `plan_resume_achievement_interview` para detectar acción, escala y resultado ausentes.
- `audit_resume_achievement_rewrite` para bloquear métricas no confirmadas.
- prompt MCP `strengthen-resume-achievements` para la entrevista conversacional.
- rutas de origen, términos para revisión y límites explícitos de verdad.
- documentación, skill y smoke local/portable actualizados.

## Seguridad

No se generan logros automáticamente, no se modifica el CV base y no se escribe ni envía información. Toda redacción requiere evidencia confirmada y revisión humana.
