# Zar Jobs AI Connector V2.0.1

V2.0.1 sustituye el icono genérico mostrado por Codex por una identidad visual propia incluida dentro del plugin.

## Novedades

- logo original de documento, Z y nodos de conexión;
- icono transparente y de alto contraste para interfaz clara y oscura;
- `composerIcon`, `logo`, `logoDark` y `brandColor` declarados en el manifiesto;
- activo local incluido en el paquete, sin alojamiento o descarga adicional;
- guía de identidad visual y uso responsable.

## Evidencia de release

- 149 pruebas automatizadas;
- 58 herramientas, 9 prompts y 3 recursos MCP sin cambios de contrato;
- manifiestos de Codex y Claude Code validados;
- smoke local y desde paquete portable;
- paquete inspeccionado para confirmar la inclusión del PNG;
- CI en Node.js 22 para Windows, Linux y macOS;
- auditoría de dependencias sin vulnerabilidades conocidas.
