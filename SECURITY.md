# Seguridad

No publiques tokens, cookies, credenciales, datos personales ni detalles explotables en una incidencia pública.

Para comunicar una vulnerabilidad, utiliza **Security → Report a vulnerability** en el repositorio de GitHub. Incluye una descripción, impacto, pasos mínimos de reproducción y una propuesta de mitigación si la conoces.

Las incidencias funcionales sin contenido sensible pueden abrirse mediante el gestor público de issues.
